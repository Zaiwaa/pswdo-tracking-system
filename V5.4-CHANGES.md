# DROMIC Production V5.4

Run `supabase/migrations/009_collaboration_workflow.sql` after migrations 005–008.

## Added / fixed
- Notifications: unread inbox now updates optimistically; read notices leave the default Unread view immediately.
- PSWDO Operations page: PSWDO/admin can create incidents and SitRep reporting cycles.
- Global notices: every approved account gets a notification for newly created incidents, reporting cycles, and provincial SitReps.
- Barangay masterlist: PSWDO can sync Pangasinan barangays from the July 2026 PSGC dataset. LGU report editor also provides an all-barangays dropdown.
- Provincial dashboard stat cards are clickable and open the matching LGU list.
- Corrected DROMIC table hierarchy: NO. OF DISPLACED → INSIDE EC / OUTSIDE EC → FAMILIES / INDIVIDUALS.
- Profile photo upload (JPG/PNG/WebP, max 3 MB) plus existing contact details.
- DROMIC direct chat between approved users, with message notifications.
- LGU `Submit No Change` workflow that creates a new immutable version by copying the previous submitted table.
- LGU `Create Changed Update` workflow: reopens the working copy without deleting historical versions. After PSWDO validates the new version it replaces that LGU's current version in a DRAFT provincial consolidation.
- Report History now exposes each submitted version and its full table.

## Barangay masterlist
The old seed file contains an incomplete subset. On the PSWDO **Incidents & SitRep Setup** page, use **Sync official barangays** once after migration 009. It imports Pangasinan records from the July 2026 PSGC dataset and upserts them into the database.
